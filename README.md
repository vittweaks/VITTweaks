## 🚀 About

VITTweaks is a modern Windows optimization tool designed for gamers who want better performance, lower latency, and a cleaner system.

Built with a futuristic cyberpunk interface, VITTweaks combines performance tweaks, Windows optimization, network improvements, and cleanup tools into one application.

## 📥 Installation

Run PowerShell as Administrator.

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
irm https://raw.githubusercontent.com/vittweaks/VITTweaks/main/install.ps1 | iex
```
